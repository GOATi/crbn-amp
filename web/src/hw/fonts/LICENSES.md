# The hardware kits' fonts

CRBN Rig's hardware kits (crbn-launcher D-RIG-009..015) letter their amps and pedals in three fonts beyond the suite's
own (`look/fonts/LICENSES.md`). Each is the Latin subset Google Fonts serves, vendored on 2026-11-11 and unchanged.

| Font | File | Licence | Text |
|---|---|---|---|
| Oswald (variable, 400 to 700), by The Oswald Project Authors | `oswald-400-700.woff2` | SIL Open Font License 1.1 | `OFL-oswald.txt` |
| Stardos Stencil (400, 700), by Vernon Adams | `stardos-stencil-400.woff2`, `stardos-stencil-700.woff2` | SIL Open Font License 1.1, Reserved Font Names "Stardos" and "Stardos Stencil" | `OFL-stardosstencil.txt` |
| Yellowtail (400), by Astigmatic | `yellowtail-400.woff2` | Apache License 2.0 | `LICENSE-yellowtail.txt` |
