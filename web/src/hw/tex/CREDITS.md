# Salvage's sheets

CRBN Rig's Salvage kit (crbn-launcher D-RIG-009..016, D-RIG-022, D-RIG-023) cuts each amp, cabinet and pedal from a photograph
of painted scrap metal. These are the photographs. Each file here is a reduced copy made for Rig, drawn into the kit
only; none of them is offered for download, and none may be taken from Rig and used as a texture.

The two 3200-pixel sheets were made on 2026-11-13 from the files each site's download gave: Pillow's Lanczos filter to
3200 pixels wide, saved as progressive JPEG at quality 82 with no metadata. Neither original carries a colour profile,
so both were taken as sRGB.

Rusted green was made the same day from the file the owner downloaded: the photograph is a door panel, so the sheet is
its clean interior at full size (pixels 105 to 2495 across and 475 to 3405 down), below the letterbox and its two bolts
and inside the panel's frame, saved as progressive JPEG at quality 82 with no metadata. It carries no colour profile
either. The original is in GOATi's texture library, `\\GOATi-SV22\Art_Resources\Textures\Metal2`.
