# Salvage's sheets

CRBN Rig's Salvage kit (crbn-launcher D-RIG-009..016, D-RIG-022) cuts each amp, cabinet and pedal from a photograph
of painted scrap metal. These are the photographs. Each file here is a reduced copy made for Rig, drawn into the kit
only; none of them is offered for download, and none may be taken from Rig and used as a texture.

| Sheet | File | Photograph | Terms |
|---|---|---|---|
| Peeling orange (the default) | `salvage-peel.jpg`, 3200x2400 | "Grunge Metal With Peeling Paint Texture Background" by [PixCrafter](https://www.pixcrafter.com/grunge-metal-with-peeling-paint-texture-background/), 5000x3750 | [PixCrafter's free licence](https://www.pixcrafter.com/license/): personal and commercial use, with a link back to the resource's page; not to be resold or redistributed |
| Scuffed red | `salvage-scuff.jpg`, 3200x2049 | "Metal 294" by [Texturelabs](https://texturelabs.org/textures/metal_294/), the 4240x2715 file | [Texturelabs' terms](https://texturelabs.org/terms/): free for commercial use as part of a larger work; no credit required; not to be redistributed |
| Rust and orange | `salvage-orange.jpg`, 1024x768 | Total Textures volume 2, Aged & Stressed, `metal/met007` (GOATi's texture library) | Total Textures' commercial licence |
| Worn red | `salvage-red.jpg`, 1024x768 | the same, `metal/met009` | the same |
| Pale blue, rust runs | `salvage-pale.jpg`, 1024x768 | the same, `metal/met011` | the same |
| Blue over red | `salvage-blue.jpg`, 1024x768 | the same, `misc/mis008` | the same |

The two 3200-pixel sheets were made on 2026-11-13 from the files each site's download gave: Pillow's Lanczos filter to
3200 pixels wide, saved as progressive JPEG at quality 82 with no metadata. Neither original carries a colour profile,
so both were taken as sRGB.
